# E32R28T 装配与首次通电

## 1. 先不要插电池

1. 核对板背面型号是触摸版 `E32R28T`，不是无触摸的 `E32N28T`，并记录 PCB
   修订号和正反面照片。
2. 查看电池座旁的 `+`、`-` 丝印。MX1.25 只是国内市场常用名称和间距描述，
   不能证明线序相同；插头能插进去也不代表极性正确。
3. 用一根可传数据的 Type-C 线连接电脑。设备管理器应出现 CH340 串口；没有串口时
   先换数据线，再安装厂家手册提供的 CH340 驱动。
4. 首次只用 USB 烧录并测试屏幕、触摸、Wi-Fi 和串口。此阶段不要把电池放在板下，
   也不要让裸露金属碰到 PCB。

## 2. 构建、烧录和配置

在项目的 `firmware` 目录执行：

```powershell
pio test -e native
pio run -e e32r28t
pio run -e e32r28t -t upload
pio device monitor -b 115200
```

如果 460800 上传不稳定，把 `firmware/platformio.ini` 中 E32 环境的
`upload_speed` 临时改为 `115200` 后重试。Type-C 自动下载通常不需要按键；只有自动
下载失败时才按厂家手册使用 BOOT/RESET 进入下载模式。

串口中配置 Wi-Fi、HTTPS 地址和只读显示令牌：

```text
set ssid YourWiFiName
set password YourWiFiPassword
set base_url https://monitor.example.com
set token qmon_REPLACE_WITH_DISPLAY_TOKEN
set timezone CST-8
set refresh_seconds 15
save
test
```

屏幕应横向显示两张配额卡。左半屏短按立即刷新、长按显示连接诊断；右半屏短按切换
30%/60%/100% 亮度、长按显示固件/IP/数据源时间。板上 BOOT 键在程序运行后也可
短按刷新、长按诊断。RESET 只复位，不是第二个用户键。

## 3. 断电核对电池极性

1. 拔掉 Type-C，确认板完全断电。
2. 电池必须是带保护板的 3.7V/1S 成品包。用万用表直流电压档测电池插头两根线：
   红表笔接电池正线、黑表笔接负线时应读到正的约 3–4.3V；若显示负号，线序与预想
   相反，禁止插板。
3. 对照实购板电池座旁的 `+/-` 丝印，确认电池正极最终进入 `+`，负极进入 `-`。
   厂家背面图在“Type-C 位于左侧、天线位于右侧”的视角显示座子左负、右正，但
   实物丝印和万用表优先，不能只按图片或红黑线颜色猜。
4. 对不上时退换或让有资质的线束人员重做成品线。不要带电退针，不要剪断两根线，
   不要直接焊电芯极耳。

## 4. 插电池和首次充电

确认极性后，捏住插头壳体平直插入；不要拉线、斜插或强推。先在开壳、不可燃表面
用电池单独启动，确认无异味、异常发热和反复重启，再接 Type-C 充电。首次充电全程
看护并记录板、电池和环境温度。异常温升、鼓包、异味、冒烟或电压异常时立即断开
USB，在确保人身安全的前提下停止使用并隔离处理。

## 5. 固定与外壳

- 电池与 PCB 焊点、屏蔽罩边缘和螺钉之间放阻燃绝缘片及软垫，并给保护板和出线口
  做应力释放；胶带只能固定保护板/线束，不能勒紧电芯。
- 电芯四周保留膨胀空间，不能被壳体、铜柱或 PCB 挤压。Type-C 插头还要留出插拔
  和线缆弯曲空间。
- 当前旧 DFRobot 外壳不能使用。收到实物后先量电池最大长宽厚、插头凸出和原配
  铜柱高度，再冻结 E32R28T 后壳；在此之前开放式绝缘固定比硬塞进壳安全。
- 完成后实测 30/60/100% 亮度功耗、充电温升和至少 8 小时续航，并保留记录。
