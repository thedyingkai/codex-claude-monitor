# E32R28T 锂电安全要求

- 只使用带保护板的 3.7V/1S 成品聚合物锂电池。禁止接 2S/7.4V 电池，禁止把裸电芯
  或没有保护板的电池直接接入模块。
- 用户购买的插头称为 MX1.25-2P，与手册的 1.25mm 2P 外形相符，但该市场名称不保证
  键位和正负极统一。断开 USB 后，用板上 `+/-` 丝印和万用表确认电池正极到 `+`、
  负极到 `-`，核对前不要试插通电。
- 禁止直接焊软包电芯极耳，禁止带电退针、同时剪断两根线、改保护板、穿刺、折弯、
  挤压或用热熔胶包覆电芯。插拔时只捏插头壳体。
- Keyes 参数页给出的模块实际充电电流约 290mA、最大 500mA、饱和电压 4.24V，
  并记录过模块实际最高充电温度 62℃。这些是厂家参数，不是“闭壳充电安全”证明；
  首次充电必须开壳、放在不可燃表面、全程看护，并以电池供应商的充电温度上限为准。
- 发现快速升温、局部烫手、异味、漏液、冒烟、鼓包或电压异常，立即停止充电；在
  保证人身安全的前提下断开 USB，把设备移离可燃物并按当地消防/危险废物要求处理。
- 电池与 PCB、屏蔽罩、焊点、螺钉之间使用阻燃绝缘片和软垫，出线做应力释放，外壳
  留膨胀空间。不得为了变薄而压紧电芯。
- 长期存放前断开电池并维持供应商建议的存储电量，远离高温、阳光、车内和软织物。
  鼓包电池不得继续充电或投入生活垃圾。

官方参数和接口说明分别见 [Keyes 产品参数](https://www.keyesrobot.cn/projects/62520093-62520094/zh-cn/latest/%E4%BA%A7%E5%93%81%E5%8F%82%E6%95%B0.html)
与 [接口定义](https://www.keyesrobot.cn/projects/62520093-62520094/zh-cn/latest/%E6%8E%A5%E5%8F%A3%E5%AE%9A%E4%B9%89.html)。
