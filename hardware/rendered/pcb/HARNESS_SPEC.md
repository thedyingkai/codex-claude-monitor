# 线束规范（R0.1 原型）

## QM-HARNESS-BAT-R01

J2 到 DFR0975 BAT 的线束不得用无图纸的通用“JST 2P 线”代替。

| 属性 | 要求 |
|---|---|
| 长度 | 100 ± 5mm，按两连接器背面出线点之间的成品长度检验 |
| 导线 | 26AWG UL1571 或等效绞线，红色为正、黑色为负；额定温度/电压不低于 80°C/30V |
| 壳体 | 2 × JST `PHR-2` |
| 端子 | 4 × JST `SPH-002T-P0.5S`，使用经校准的适配压接工具 |
| 接法 | J2.1 `VBAT_SAFE` 到 DFR0975 BAT 正极；J2.2 `GND` 到 BAT 负极 |
| 拉力 | 每个压接端子按线束供应商工艺做拉力抽检，端子倒刺必须锁入壳体 |

DFR0975 BAT 端 pin 1/正极位置必须以**实际采购板的丝印、原理图和万用表**三方
复核后才允许建立首件。首件先不接电池，用限流电源确认 J2.1 到 BAT+、J2.2 到
BAT− 的端到端电阻均小于 0.2Ω，且两线之间开路；随后封存一件金样。壳体方向或
线色与本规范不一致即判不合格。

电池供应商安装的 PHR-2 同样必须以正极对 J1.1 `BAT_RAW`、负极对 J1.2 `GND`
为准做 100% 极性检验；不能假设不同供应商的红黑线序天然一致。

## QM-HARNESS-AUX-R01

封闭外壳版本不装 J5 的 Samtec 竖直排针。原型可从 J5 镀通孔低矮焊出 6 根
26--28AWG 软线，并在载板边缘做绝缘应力释放：

| J5 | DFR0975 | 功能 |
|---:|---|---|
| 1 | GPIO47 | 按键 A |
| 2 | GPIO8 | 按键 B |
| 3 | GPIO5 | 软关机拨动开关 |
| 4 | VCC | USB/电池电压检测源 |
| 5 | GND | 公共地 |
| 6 | GPIO6 | 100k/100k 分压后的 ADC |
| 7 | 不装 | MAX17048 ALERT，v1 固件未使用 |

DFR0975 端的低矮连接方式、线长、固定点和绝缘方式尚未经过实物堆叠验证，所以
`QM-HARNESS-AUX-R01` 仍是原型图号，不得发给量产线。开放式调试可临时装
`TSW-107-07-G-S`，但它与当前屏幕/外壳 Z 包络冲突。

DFR0975 的 VCC 在 USB 供电时约为 5V，在仅电池供电时会跟随单节电池电压；它不是
纯 USB VBUS。载板 R3/R4 分压后，固件以约 2.25V 阈值和滞回区分两种状态。首件
必须测量满电 4.2V、电池低压、USB 最低输入和 ADC 公差四个角点，确认没有误判。
